The game is  Kalari Fury, with Street Fighter-style fighters, dark Mortal Kombat-style stages that you can smash up, and mixed controls.
Controls (mixed)

Action	Keys
Move / jump / crouch	A D / W / S
Low punch / high punch	U (or click) / I
Low kick / high kick	J / K
Block	Shift or L, or just hold back when an attack is coming
Dash	Space
Fireball	S, then S + forward, then forward + punch
Rising fist	forward, then S, then S + forward, plus punch
Hurricane kick	S, then S + back, then back + kick
